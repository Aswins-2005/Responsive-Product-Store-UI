# Responsive Product Store UI 🛍️

A clean and responsive e-commerce product store interface built using HTML and CSS. This project focuses on creating reusable product card layouts and adapting the user interface to different screen sizes using CSS Grid and media queries.

## ✨ Features

- Responsive product grid layout
- Product cards with images, names, and prices
- Navigation bar with a clean layout
- Promotional banner for desktop screens
- Hover effects on product cards and buttons
- CSS Grid for product arrangement
- Media queries for tablet and mobile responsiveness
- Google Fonts integration using Open Sans
- Consistent spacing, shadows, and rounded corners

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Google Fonts

## 📱 Responsive Design

The interface adapts to different viewport sizes using CSS media queries.

- **Desktop:** Three-column product layout.
- **Tablet:** Two-column product layout.
- **Mobile:** Compact product cards with adjusted spacing and typography.
- **Small mobile:** Single-column product layout for screens up to 360px.
- **Mobile banner:** Hidden on screens 768px and below.
